# Task Guides

These guides provide an awesome-style navigation layer over the catalog. They
help readers narrow a concrete simulation task to a small set of candidate
projects, then link back to the full metadata and evidence entries.

They are selection guides, not universal rankings or automated recommendations.
Every recommendation should be read together with the project's catalog entry,
license, maintenance status, simulation scope, and evidence level.

## Guide conventions

- Facts should link to official project documentation or the catalog entry.
- Assessments should be stated as task-specific trade-offs.
- Pending or reference-only projects should not be presented as reviewed
  recommendations.
- A guide should link to the primary catalog page instead of duplicating the
  complete metadata block.
