# Examples

This directory contains small, runnable examples for readers. Each example should be self-contained, concise, and explicit about dependency versions and expected output.

Recommended contents for each example:

- `README.md`
- `requirements.txt` or an equivalent dependency file
- Source code
- A fixed input set
- Run commands and a screenshot or numerical summary of the result
